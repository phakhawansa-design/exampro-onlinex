# ตรีเนตร e-Exam · ตาที่ 3 ของอาจารย์

ระบบสอบออนไลน์ที่รวม 2 ส่วนไว้ในเว็บเดียว

- **ตาเฝ้า (ระหว่างสอบ):** ตรวจจับการสลับหน้าจอ ย่อหน้าต่าง หรือคลิกโปรแกรมอื่น บันทึกเวลา จำนวนครั้ง และข้อที่กำลังทำ แจ้งอาจารย์ผู้คุมสอบแบบเรียลไทม์ ล็อกคีย์ลัดคัดลอก/วาง บังคับเต็มจอบนคอมพิวเตอร์ และจับการหายไปจากหน้าสอบ (พับแอป/ล็อกจอ) จากสัญญาณที่ขาดหาย
- **ตาอ่าน (หลังสอบ):** นำเข้า PDF กระดาษคำตอบ อ่านลายมือด้วย AI เทียบกับเฉลยและ Rubric แล้วเสนอคะแนนรายข้อพร้อมเหตุผลให้อาจารย์ยืนยัน
- **ตาสองดวงทำงานร่วมกัน:** รายงานรวมรายคน (คะแนนปรนัย + อัตนัย + ประวัติตาเฝ้า) และคิวตรวจอัตนัยที่ให้คนมีประวัติสลับหน้าจอขึ้นก่อน

## พิมพ์กระดาษคำตอบ → สแกนกลับอัตโนมัติ

1. หน้าตรวจอัตนัย สร้างงานและเลือกรายวิชา แล้วกด **🖨️ พิมพ์กระดาษคำตอบ** ระบบสร้างกระดาษคนละชุด เติมชื่อ-นามสกุล รหัส ชั้นเรียนให้ (เลือกพิมพ์เฉพาะชั้นเรียนได้)
2. พิมพ์ขนาด A4 ระยะขอบ "ไม่มี" และขนาด 100%
3. หลังสอบ สแกนกระดาษทั้งห้องเป็น PDF ไฟล์เดียว (ลำดับสลับกันหรือกลับหัวได้)
4. กด **นำเข้า PDF** เลือกโหมด **อ่านรหัสตรีเนตรอัตโนมัติ** ระบบแยกเป็นรายคน ใส่ชื่อให้ แล้วส่งให้ AI ตรวจ หน้าที่อ่านรหัสไม่ได้จะแยกไว้ให้แก้ชื่อเอง

## ติดตั้งและรันในเครื่อง

ต้องมี Node.js 20

```bash
npm install
cp .env.example .env     # แล้วแก้ค่าใน .env
npm start
```

เปิด `http://localhost:5000`

บน Windows ดับเบิลคลิก `ExamPro_Launcher.bat` ได้เลย (ต้อง `npm install` ก่อนครั้งแรก)

## ตั้งค่า (.env)

ดูตัวอย่างทั้งหมดใน `.env.example` ค่าที่สำคัญ:

| ตัวแปร | ความหมาย |
|---|---|
| `PORT` | พอร์ตของเว็บ (ค่าเริ่มต้น 5000) |
| `DATABASE_URL` | ถ้าใส่ จะใช้ PostgreSQL (เช่น Neon) ถ้าไม่ใส่ จะใช้ SQLite ในโฟลเดอร์ `.data` |
| `AUTH_SECRET` | ข้อความสุ่มยาว ๆ สำหรับเซ็น token **ควรตั้งบนโฮสต์จริง** |
| `ANTHROPIC_API_KEY` | key ของ Claude สำหรับตรวจอัตนัยและสร้างข้อสอบ |
| `ADMIN_PASSWORD` | รหัสผ่านแอดมินตอนสร้างระบบครั้งแรก ถ้าไม่ใส่จะเป็น `admin123` และระบบ**บังคับตั้งรหัสใหม่**ตอนเข้าสู่ระบบครั้งแรก |
| `WATCH_GAP_SECONDS` | สัญญาณจากหน้าสอบขาดกี่วินาทีจึงบันทึกว่า "หายจากหน้าสอบ" (ค่าเริ่มต้น 15) |
| `ALLOW_INAPP_BROWSER` | ใส่ `on` ถ้าจำเป็นต้องให้สอบในเบราว์เซอร์ของ LINE/Facebook ได้ (ไม่แนะนำ) |

> ⚠️ อย่าอัปโหลดไฟล์ `.env` ขึ้น GitHub เด็ดขาด ใส่ค่าเหล่านี้ในหน้าตั้งค่า Environment Variables ของโฮสต์แทน (`.gitignore` กันไว้ให้แล้ว)

## ข้อควรรู้

- **ใช้ Neon แผนฟรี:** ย้อนข้อมูลได้แค่ 6 ชั่วโมง ควรกด "💾 ดาวน์โหลดข้อมูลสำรอง" ในหน้า Super Admin หลังสอบทุกครั้ง ส่วนไฟล์ภาพกระดาษคำตอบเก็บบนดิสก์ของเครื่องที่รันเว็บ ไม่ได้อยู่ใน Neon
- นักศึกษาเข้าสอบได้ทีละเครื่อง/แท็บเดียว ถ้าเปิดซ้อน ระบบไม่ให้เข้าและแจ้งอาจารย์ ถ้าเครื่องเดิมปิดไปแล้วให้รอประมาณ 15 วินาที
- เข้าสอบผ่าน QR/ลิงก์ต้องกรอกรหัสผ่านทุกครั้ง (ครั้งแรกใช้ 1234 หรือ 4 หลักท้ายของรหัสนักศึกษา แล้วระบบให้ตั้งรหัสใหม่)
- เข้าสู่ระบบแอดมินครั้งแรกด้วย `admin / admin123` แล้วระบบจะให้ตั้งรหัสใหม่ทันที (บัญชีเดิมที่ยังใช้ admin123 ก็ถูกบังคับเหมือนกัน)
- ระหว่างสอบ คำตอบถูกบันทึกทุกครั้งที่เลือก ถ้ารีเฟรช แบตหมด หรือเน็ตหลุด กลับเข้ามาจะได้คำตอบเดิมและเวลาเดินต่อจากเดิม (ไม่เริ่มนับใหม่)
- สอบบนคอมพิวเตอร์ต้องอยู่ในโหมดเต็มจอ การออกจากเต็มจอถูกบันทึกให้อาจารย์เห็น (มือถือ/แท็บเล็ตไม่บังคับ)
- ไฟล์กระดาษคำตอบที่อัปโหลดเป็นข้อมูลส่วนบุคคลของนักศึกษา (PDPA) ระบบลบไฟล์ภาพอัตโนมัติตาม `ESSAY_RETENTION_DAYS`
- โฮสต์บางเจ้าลบไฟล์บนดิสก์ทุกครั้งที่ deploy ใหม่ ถ้าใช้ SQLite ควรตั้ง `DATA_DIR` ไปที่ดิสก์ถาวร หรือใช้ `DATABASE_URL` (PostgreSQL)
- ส่งลิงก์ห้องสอบทาง LINE ได้ ลิงก์จากหน้าห้องสอบมี `openExternalBrowser=1` ให้ LINE เปิดใน Safari/Chrome ส่วนแอปอื่นนักศึกษาจะเห็นหน้าแนะนำให้เปิดในเบราว์เซอร์หลักก่อนสอบ
- การสลับหน้าจอไม่ได้แปลว่าทุจริตเสมอ ระบบบันทึกเพื่อให้อาจารย์ใช้ประกอบการพิจารณา
